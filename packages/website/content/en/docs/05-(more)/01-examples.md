## Included with the app

Copy an example into your own project folder before editing it.

- **macOS:** in Finder, right-click Celesta in Applications, choose **Show Package Contents**, then open `Contents/Resources/examples`.
- **Windows:** open the `examples` folder beside `Celesta.exe` in the installed or portable app folder.

The repository’s `packages/cli/examples` directory contains more scenes covering text, animation, layout, dialogue, lip sync, and editable project properties. Download the source archive, extract it, and open a supported entry through **File → Open…** in the installed app; no source build is needed.

[Browse all source examples on GitHub ↗](https://github.com/mika-f/Celesta/tree/main/packages/cli/examples)

You can also [open the web editor](/en/#playground), edit or import a self-contained `.tsx` composition, preview frames, and export MP4 directly. Download the source to keep editing it in Celesta.
