**File → Open…** で React コンポジション（`.tsx`、`.jsx`、`.ts`、`.js`）を開きます。素材、トラック、クリップを選ぶと、Inspector で詳細を確認できます。

> [!NOTE]
> **ソースがキャンバス**
> コンポジションはテキストエディタで編集します。Celesta でプレビューと書き出しを行い、ソースを保存すると表示が更新されます。

ソースを保存すると自動で再読み込みされます。**File → Reload** で手動更新することもできます。

## 映像と一緒に音を確認

再生時は映像と音声が同期します。波形とトラックレベルでタイミングを確認し、ミュートやソロで音を切り分け、プレビュー音量を調整できます。タイムラインの目盛りをドラッグすると好きな時点に移動できます。

## プレビュー専用のガイド

`<DebugOverlay />` はフレームの外枠、セーフエリア、中心を描画し、`<DebugBounds>` はレイヤーのグループに枠を付けます。どちらもプレビューにだけ表示され、書き出しには含まれないので、作業中は残しておけます。`useIsPreview()` で自作コンポーネントもプレビューかどうか判定できます。
