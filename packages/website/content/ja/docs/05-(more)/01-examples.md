## アプリに同梱のサンプル

編集する前に、自分のプロジェクトのフォルダへコピーしてください。

- **macOS：** Finder の Applications で Celesta を右クリックし、**パッケージの内容を表示**を選び、`Contents/Resources/examples` を開きます。
- **Windows：** インストール先やポータブル版の `Celesta.exe` の隣にある `examples` を開きます。

リポジトリの `packages/cli/examples` には、テキスト、アニメーション、配置、台詞、口パク、編集可能なプロパティなどのシーンがあります。ソースのアーカイブを取得・展開し、アプリの **File → Open…** で対応するエントリーを開きます。ソースのビルドは不要です。

[GitHub ですべてのサンプルを見る ↗](https://github.com/mika-f/Celesta/tree/main/packages/cli/examples)

[ウェブエディタを開き](/ja/#playground)、単一ファイルの `.tsx` を編集・インポートして、プレビューと MP4 書き出しを試すこともできます。Celesta で編集を続けるにはソースをダウンロードしてください。
