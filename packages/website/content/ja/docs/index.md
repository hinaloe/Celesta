Celesta は、React と TypeScript のコードで動画を作るツールです。デスクトップアプリで動きを確認し、MP4 動画や PNG 画像に書き出せます。

- **ここからはじめる →**\
  [Celesta をインストール。](/ja/docs/installation/)\
  アプリをダウンロードして、最初のシーンを開きます。
- **次のステップ →**\
  [最初のコンポジション。](/ja/docs/react-compositions/)\
  5 秒の React タイトルカードを、最初から最後まで。

**01** エディタで書く → **02** Celesta で確認 → **03** MP4 に書き出す

まずは macOS または Windows 用アプリをダウンロードしてください。開発者や Linux ユーザー向けに、ソースからのビルド手順も用意しています。Celesta は MIT または Apache-2.0 のオープンソースです。
