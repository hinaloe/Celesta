# Subtitle pages assets

Fixture for `packages/cli/examples/with-subtitle-pages.tsx`: one long
utterance whose subtitle pages through while the voice plays on.

| Path | What | License |
| --- | --- | --- |
| `danger.txt` | The kana the recording says: the line's `spokenText` | Same as this repository (MIT OR Apache-2.0) |
| `danger.wav` | 16 kHz PCM recording of `danger.txt`, made with the macOS "Kyoko" system voice, like `examples/assets/voices/001.wav` | Same as `001.wav` |
| `generate.sh` | Regenerates the WAV from the text (macOS only) | Same as this repository |
